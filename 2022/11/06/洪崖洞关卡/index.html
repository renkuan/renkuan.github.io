关卡介绍

简介

  • 关卡定位：基于《最后生还者》的世界观氛围与基础玩法框架，将故事舞台转移至中国重庆，并以洪崖洞建筑群作为核心场景参考，尝试融合“末日生存”与“魂系箱庭”两种关卡设计思路。
  • 使用工具：UE4、UE4 Blueprints、Blender、UE4-IWALS
  • 开发周期：3 周
  • 负责内容：关卡概念设计、逻辑结构设计、白盒搭建、玩法脚本、AI 配置、敌人布置、事件触发、拾取物系统与过场动画制作

关卡演示与解说

我做了什么

  • 完成从概念设计到可玩 Demo 的完整关卡流程设计
  • 撰写玩法设定文档，绘制关卡逻辑图、流程图与地图草图
  • 使用 Blender 与 UE4 进行关卡白盒搭建、空间布局与尺度验证
  • 整合核心游戏元素，包括 敌人布置、AI 战斗巡逻逻辑调试、事件触发机制、拾取物系统、存档点等。
  • 使用 UE4 蓝图编写关卡脚本，实现门、电梯、捷径、触发器等交互功能
  • 使用 UE4 Sequencer 制作关卡过场动画与关键演出节点

设计目标

本项目的核心目标，是尝试回答一个具体的设计问题：

如果将《最后生还者》的末日生存玩法，与魂系箱庭地图结构结合，会产生怎样的关卡体验？

围绕这一目标，我设定了以下设计方向：

  • 制作一个具有非线性探索结构的《最后生还者》式箱庭关卡
  • 关卡体量参考魂类游戏中的中型箱庭区域，完整游玩流程约为 50–60 分钟
  • 将重庆作为故事发生地，塑造具有中国地域特征的末日废墟城市景观
  • 借助“类魂拓扑学”的分析方法，实现局部开放探索与整体回溯探索结合的关卡体验
  • 验证魂系关卡设计方法是否可以迁移到其他题材与玩法类型中

设计过程

重庆地形为何适合魂系箱庭设计

我选择洪崖洞作为关卡原型，是因为重庆山城地貌天然具备魂系箱庭关卡所需要的几个关键空间特征。

魂系箱庭需求 重庆 / 洪崖洞提供的空间条件
强烈的垂直高差 吊脚楼建筑群依山而建，存在 6–11 层的空间落差，垂直高度超过 50 米
多层路径交叠 栈道、防空洞、轻轨、桥梁等交通系统分布在不同标高上
清晰的视觉地标 千厮门大桥、迎宾楼牌坊等远景地标，有助于玩家建立空间记忆
末日氛围合理性 防空洞、轻轨站、临江沉船等基础设施，为灾后废墟提供了可信载体

重庆地形本身提供了一套“开箱即用”的箱庭骨架。相比从零开始创造复杂空间，借助现实中已经存在的高差、道路与建筑关系，能够更自然地生成多层路径、捷径回环和视觉地标。

因此，我将关卡的主要方向确定为：

以洪崖洞吊脚楼群为主体，在悬崖、栈道、防空洞与跨江大桥之间，搭建一个垂直交错、路径回环明显的立体箱庭关卡。

将“类魂拓扑学”落地到洪崖洞

“类魂拓扑学”是一种用图论和拓扑关系分析魂系地图结构的方法。它将关卡拆解为开放区域、路径与兴趣点，并通过节点之间的连接关系评估地图的探索性、回环性与稳定性。

参考文章：如何设计一张有“魂味”的地图？——论“类魂”游戏关卡的拓扑结构

在这个项目中，我主要借用了其中关于最简逻辑图、常用子图结构和连通度验证的思路，用它来指导关卡早期结构设计。

1. 绘制最简逻辑图

在关卡初期，我先根据场景主题与玩法需求，将洪崖洞拆分为几个核心区域：

  • 滨江路沉船区
  • 洪崖滴翠亭
  • 吊脚楼
  • 栈道
  • 防空洞
  • 迎宾楼废墟
  • 千厮门大桥

随后，我根据预估的关卡体量与连通度需求，从常见的类魂子图结构中选择合适的结构进行组合，并通过“键”连接不同子图，形成整体逻辑图。

大致流程如下：

  • 根据场景概念划分核心区域与 POI
  • 选择适合关卡规模的常用子图结构
  • 使用“键”连接多个子图，形成初步逻辑结构
  • 根据连通度公式进行估算与验证
  • 反复调整节点关系，避免结构过线性或过度复杂

这张图的作用不是描述具体空间，而是验证关卡的基础结构是否成立：
玩家是否能形成回环认知、分支是否最终归并、捷径是否能带来空间理解上的奖励。

2. 从最简逻辑图推导自然逻辑图

在确定最简逻辑图后，我开始使用大体块在 3D 空间中搭建关卡骨架，并根据实际空间尺度、地形高差和玩家视线，推敲节点之间的连接方式。

需要说明的是，逻辑图设计与 3D 白盒搭建并不是前后完全分离的流程。实际开发中，两者往往是同步推进、互相验证的：

  • 逻辑图用于控制关卡结构与连通度
  • 3D 白盒用于验证空间尺度、视线引导和玩家动线
  • 当白盒中的路径不成立时，需要回到逻辑图重新调整
  • 当逻辑图过于抽象时，也需要通过 3D 空间补充具体节奏

经过多轮调整后，我得到了如下自然逻辑图：

这张图将整张关卡拆解为多个 POI 节点，并标记它们之间的连接关系，包括主路径、分支路径、捷径回环和单向门。

它不关注具体几何尺寸，而是关注逻辑可达性：

  • 哪些节点之间可以互相抵达
  • 哪些路径是单向推进
  • 哪些路线承担捷径功能
  • 分支探索是否会自然回到主线
  • 玩家是否能通过地标和回环建立空间记忆

从图上可以看到，主线路径形成了一个较大的 U 形回环，同时包含若干通向收藏品 POI 的次级分支。

3. 设计关卡目标

在世界观设定中，“舌火帮”是我结合川渝地区民俗与饮食文化虚构出的末日帮派势力。玩家来到洪崖洞后，需要追踪舌火帮的活动痕迹，最终击败其首领并获得关键情报。

主要目标：追踪舌火帮，击败首领并获取情报

主线流程如下：

  1. 玩家乘船抵达滨江路沉船区域，在被洪水淹没的城市废墟中开始探索
  2. 沿着废墟楼梯向上，抵达洪崖滴翠亭
  3. 穿越下层防空洞，击杀感染者，并前往吊脚楼区域
  4. 清理吊脚楼屋顶与建筑内部的舌火帮成员，抵达栈道入口
  5. 沿栈道进入防空洞深处，穿越洞穴后抵达迎宾楼废墟
  6. 在迎宾楼露台击败阶段性 BOSS，进入建筑内部探索
  7. 通过二层电梯前往千厮门大桥
  8. 在桥面与轻轨残骸区域击败最终 BOSS

次要目标：探索洪崖洞各个区域

除了主线推进外，关卡中还设置了多个探索目标：

  • 探索沉船、迎宾楼阳台、防空洞下层、千厮门轻轨站等区域
  • 搜集散落在地图各处的食物配方
  • 通过报纸、便条和场景痕迹补完世界观信息
  • 发现捷径，建立对洪崖洞立体空间的整体认知

4. 关卡节奏设计

节奏图用于控制整段流程中的体验强度变化。
我将关卡体验大致拆分为探索、潜行、战斗、缓冲与 BOSS 战几个段落，并根据玩家压力曲线安排不同玩法内容。

设计原则包括：

  • 高强度战斗后安排低密度探索，避免持续疲劳
  • 在新敌人或新机制出现前，预留观察和学习空间
  • 通过防空洞等低光照区域制造压迫感和资源焦虑
  • 逐步提高战斗密度，最终在千厮门大桥迎来高潮
  • 在最终 BOSS 战后结束关卡，避免高潮后的体验塌陷

整体节奏从低强度探索开始，经过多次战斗与探索交替，最终在大桥区域集中爆发。

2. 主要区域设计

滨江路沉船

  • 场景特征：被洪水淹没的滨江公路与汽车坟场
  • 玩法定位：开局教学区
  • 节奏定位：低强度探索 + 1–2 场基础遭遇战

这个区域的灵感来自洪灾后城市低洼地带被江水吞没的景象。
我将其设计为关卡的开场区域：玩家乘船来到洪崖洞，在被水淹没的建筑废墟与车辆残骸之间开始探索。

该区域主要承担教学功能：

  • 引导玩家熟悉基础移动与观察
  • 介绍射击、潜行和资源拾取
  • 通过较低强度的敌人配置，让玩家理解关卡的末日氛围
  • 利用远处的洪崖洞建筑群和千厮门大桥建立早期目标感

洪崖滴翠亭

  • 场景特征：破败的仿古建筑、山体瀑布与多层平台
  • 玩法定位：前半段核心枢纽点
  • 节奏定位：中等强度遭遇战 + 垂直空间利用教学

洪崖滴翠亭是前半段流程的重要枢纽，连接多个 POI，并包含由两个环路组成的局部箱庭结构。

该区域的设计重点是让玩家第一次明确感受到关卡的垂直特征：

  • 玩家可以从多个方向观察后续区域
  • 区域内部存在小型回环，帮助玩家理解“探索—战斗—开启捷径”的基本节奏
  • 远处地标持续出现在视野中，辅助玩家建立空间方位感

吊脚楼

  • 场景特征：川渝地区特色吊脚楼建筑群
  • 玩法定位：复合型战斗场地
  • 节奏定位：高密度战斗 + 潜入分支

吊脚楼区域是玩家首次正面遭遇“舌火帮”人形敌人的位置。
这里同时包含屋顶、室内房间、走廊和外部连廊，形成多层交错的战斗空间。

由于吊脚楼本身具有现代建筑特征，空间形态相对规整，因此我将重点放在潜入路线与交火路线的双解设计上：

  • 玩家可以选择从屋顶高处观察并逐步清理敌人
  • 也可以从建筑内部潜入，利用房间和走廊分割敌人视线
  • 建筑外部连廊提供侧翼包抄路线
  • 室内空间提供资源补给和环境叙事内容

这个区域用于验证玩家是否可以在同一片空间内，以潜入或正面战斗两种方式完成目标。

防空洞

  • 场景特征：阴暗、狭窄、压迫感强的地下洞穴
  • 玩法定位：连接型潜行 / 恐怖区域
  • 节奏定位：低光照、低视野、高资源压力

防空洞曾是战时避难设施。病毒爆发后，部分幸存者躲入其中，但最终被感染者占据。
因此，这一区域既是空间连接点，也是氛围转换点。

防空洞区域的设计重点包括：

  • 使用低光照和狭窄通道削弱玩家安全感
  • 通过声音和视线遮挡制造感染者威胁
  • 让玩家在近战、弹药和治疗资源之间做取舍
  • 将资源管理压力推向前半段流程的峰值

与外部开阔区域相比，防空洞提供了截然不同的体验节奏。它让玩家从城市废墟中的探索，转入更接近恐怖生存的压迫段落。

迎宾楼废墟

  • 场景特征：商业建筑废墟、露台、店铺与室内空间
  • 玩法定位：阶段性 BOSS 战场地 + 室内探索区
  • 节奏定位：露台 BOSS → 室内缓冲探索 → 电梯转场

迎宾楼废墟是关卡后半段的重要节点。
玩家在露台遭遇阶段性 BOSS，战斗结束后进入建筑内部进行探索，并最终通过二层电梯前往千厮门大桥。

该区域承担三个功能：

  1. 战斗高潮：露台空间提供较大的机动范围，适合阶段性 BOSS 战
  2. 新增探索体验：室内探索阶段提供了一种在高处走独木桥的刺激恐怖感。
  3. 叙事补完：通过食物配方、报纸、便条和生活痕迹，补充舌火帮与灾后城市的信息

作为洪崖洞的商业区域，迎宾楼废墟中保留了大量人类活动痕迹。
这些内容可以增强末日世界的可信度，也让玩家在高强度战斗后获得叙事层面的回报。

千厮门大桥

  • 场景特征：跨江大桥、轻轨轨道与坠落车厢残骸
  • 玩法定位：终局遭遇战场
  • 节奏定位：远距离交火 + 闭塞空间突围 + 最终 BOSS 战

千厮门大桥是整张关卡的终点，也是视觉和节奏上的高潮区域。
桥面空间开阔，适合布置长距离交火、狙击敌人和压迫式推进。

该区域由两个主要段落构成：

  • 桥面战斗：玩家需要利用车辆残骸与桥体结构作为掩体，在敌人换弹和火力间隙中推进
  • 轻轨车厢战斗：进入坠落的轻轨残骸后，空间变得狭窄，节奏转为近距离遭遇和最终 BOSS 战

从高处坠落的轻轨车厢既是视觉奇观，也是结构上的关键路径。
它连接了千厮门大桥与关卡起点附近的滨江路区域，使整张地图在终点处完成一次大的空间回环。
